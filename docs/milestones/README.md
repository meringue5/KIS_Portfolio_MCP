# 인수 기준선과 운영 변경

일상 작업은 [운영 모델](../operating-model.md)과 [기능 지도](../traceability.md)에서 시작합니다.
현재 인수 범위·미지원 경계·운영 변경 원칙은 [V2 인수 의미](v2-acceptance.md) 한 곳에 정리했습니다.

이 폴더에는 Wave별 해야 할 일·실행 일지·revision timeline을 유지하지 않습니다. delivery는 종료됐고,
과거 과정은 [원문 압축본](../history/README.md#인수와-구축-경과)에서 필요할 때 확인합니다.
identity/depends_on/sequence의 정본 [registry](../../governance/project/milestones.toml)와 개별 [WI](../work-items/)는 보존합니다.
운영 maintenance의 추적은 계속하지만 완료된 milestone을 다시 구현 계획으로 읽지 않습니다.
